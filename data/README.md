# Data

The patient-level SEER dataset used in the associated study is not distributed with this repository.

The study uses oral cancer records obtained from the Surveillance, Epidemiology, and End Results (SEER) database. Researchers interested in reproducing the analysis should obtain the appropriate SEER research data through the official SEER access procedures.

After obtaining the data, prepare the analysis dataset according to the inclusion criteria, feature definitions, and encoding procedure described in the associated manuscript.

Patient-level data should not be committed to this repository.
